# Yaitso OS 0.3.3

Yet Another Independent Typical Stable Origin OS

**English version:** [README.md](README.md)

## Что нового в 0.3.3

Версия 0.3.3 делает систему пригодной для повседневной работы: полноценный
рабочий стол, настоящий установщик и исправленная сессия входа.

### Рабочий стол (ycomp/ybar/ylaunch)
- серверные заголовки окон с кнопками «свернуть/развернуть/закрыть»
- перетаскивание за заголовок, изменение размера за края и углы
- maximize/restore, привязка к половине экрана, сворачивание и
  восстановление окон
- двойной щелчок по заголовку — развернуть/восстановить
- горячие клавиши: `Super+Return` (терминал), `Super+D` (запуск программ),
  `Super+Q` (закрыть), `Super+M` (развернуть), `Super+←/→` (половина
  экрана), `Super+H` (свернуть), `Super+Tab`/`Alt+Tab` (переключение)
- ybar: кликабельная кнопка APPS, список окон с переходом по клику,
  подсветка активного и свёрнутых окон, дата и часы
- ylaunch: запуск мышью, прокрутка списка, PageUp/PageDown/Home/End,
  поиск и русские подписи; окно центрируется композитором
- мягкий градиентный фон рабочего стола и настраиваемые цвета
- IPC-команды `maximize`, `restore`, `toggle`, `minimize`, `unmaximize`,
  `snap`, `next`, `prev`; `list` сообщает признак свёрнутого окна

### Установщик
- полностью переписанный `yaitso-install`: разметка GPT (UEFI и BIOS),
  `parted`/`sfdisk`, `mkfs.ext4`/`mkfs.vfat`, UUID в `/etc/fstab`
- копирование системы собственным кодом на C, без внешних `cp`/`rsync`
- создание пользователя, SHA-512 хеш пароля, блокировка root
- установка GRUB для UEFI и BIOS, резервный `BOOTX64.EFI`
- отдельный минимальный initramfs установленной системы: busybox и драйверы
  накопителей, `/init` монтирует корень и делает `switch_root`
- режим загрузки «Yaitso OS (install)» с `yaitso.install=1`
- параметры командной строки: `--list`, `--disk`, `--hostname`, `--user`,
  `--password`, `--gui/--no-gui`, `--efi/--bios`, `--yes`, `--force`
- статическая сборка: работает в минимальном live-rootfs
- в live-образ попадают `parted`, `e2fsprogs`, `dosfstools`, `grub` и
  нужные им библиотеки

### Сессия и система
- init всегда запускает `getty`/`login`, а `login` после аутентификации
  запускает `start-desktop`; после выхода снова появляется приглашение входа
- live-образ входит автоматически (`/etc/yaitso/autologin`), установленная
  система этот файл не содержит
- `start-desktop` корректно готовит `XDG_RUNTIME_DIR`, Wayland-переменные и
  ждёт появления сокета композитора
- mkiso: ссылки на applet'ы busybox (`cp`, `tar`, `find`, `grep`, `df`,
  `free`, `touch`, `mktemp`, `realpath` и др.) — в live-системе работают
  привычные команды
- mkiso: ядро и initramfs теперь есть внутри live-системы, поэтому
  установщик может установить загрузчик и ядро

### Исправления
- зависание и «уезжание» окна при перетаскивании и изменении размера
- панель больше не забирает клавиатурный фокус
- первый configure теперь получают и панель, и лаунчер: ybar больше не
  падает с ошибкой `xdg_surface has never been configured`
- окна не выходят за пределы рабочей области, заголовок всегда доступен
- `list` в IPC не ломался на окнах без заголовка
- IPC-сокет создаётся в `$XDG_RUNTIME_DIR` — панель работает от обычного
  пользователя, а не только от root

## Что было в 0.3.2

Версия 0.3.2 — выпуск исправлений: безопасность, стабильность и корректная
работа оболочки, GUI и системных утилит.

### Безопасность
- login/passwd/su/sudo: настоящая проверка пароля через `/etc/shadow`
  (`getspnam` + `crypt`), запрет пустых и заблокированных хешей
- login: проверка имени пользователя и безопасные пути ban-файлов
- passwd: проверка старого пароля, атомарная запись shadow (0600, root)
- sudo: сброс дополнительных групп через `setgroups(0, NULL)`
- useradd/userdel: атомарная запись passwd/group/shadow, проверка имён,
  удаление домашнего каталога без `system()`
- yat/svc/yglibc: проверка имён, путей и границ буферов

### Оболочка yaitso
- корректный разбор редиректов: `2>&1`, `1>&2`, `2>`, `2>>`, `1>`, `1>>`,
  `&>`, `&>>`, `>`, `>>`, `<`, кавычки и экранирование
- фоновые команды через `&`, конвейеры больше не «съедают» фоновые задания
- встроенные команды работают внутри конвейера
- позиционные параметры `$0..$9`, `$#`, `$@`, `$*`, `${N}`, `${#}`
- `-c [--] команда` и передача аргументов скрипту
- `printf`: backslash-последовательности и повтор формата
- `tail -n 0` и отрицательные значения без деления на ноль
- histsize реально ограничивает историю
- UTF-8: безопасный подсчёт длины обрезанных последовательностей

### Графика и GUI
- ycomp: создаётся `wl_compositor`/`wl_subcompositor`/data-device — окна
  клиентов действительно появляются, а не остаются чёрным экраном
- ycomp: первичный configure xdg-окон и layer-surface, панель ybar на всю
  ширину сверху, корректный атомарный DRM-режим и первый кадр
- ycomp: резервный ввод напрямую из `/dev/input/event*`, если backend не
  создал устройств (минимальный rootfs без udev/libinput)
- ycomp: встроенная раскладка US, если в системе нет `/usr/share/X11/xkb`
- libywt: слушатель `wl_seat` вешается до события `capabilities`, поэтому
  клавиатура и указатель клиентов работают; разбор keymap без include-путей
- ybar: подсветка активного окна через IPC (id + focus)
- ylaunch: `%%` в .desktop и правильная передача argv в `yterm -e`
- ytui: корректный цвет фона и неблокирующий ESC
- start-desktop: поиск любого `/dev/dri/cardN` с ожиданием до 10 секунд,
  автозапуск yterm и журнал `/var/log/ycomp.log`
- init/mkiso: загрузка `psmouse`/`usbhid` — мышь и клавиатура в QEMU и на
  обычном железе
- yterm: UTF-8 и CSI-последовательности, переживающие границы `feed()`

### Утилиты
- ybox: собственные рекурсивные `cp` и `chown` (имена пользователей/групп)
- yat: рабочий `upgrade` (сравнение версий, только более новые пакеты)
- svc: запуск сервисов от указанного пользователя, проверка имени сервиса
- yglibc verify: поиск зависимостей по всему файлу
- pbkdf2: защита от переполнения при длинной соли

### Из 0.3.1
- glibc 2.40 в `/usr/glibc`, утилита `yglibc`, пакеты `glibc-*`
- `firefox` (ESR 128) через `yat install firefox`
- yterm: вкладки, поиск, bracketed paste, bell, `--test-color`


## Сборка

    make
    make gui
    make test
    make check
    make repo repo-sign
    sudo make iso-gui
    make qemu-gui

Собранные исполняемые файлы, объектные файлы и каталог `gui-out` в
репозитории не хранятся: их создают `make` и `make gui`.

## Установка Firefox

    yat install firefox
    firefox

## Требования хоста

    wayland, wayland-protocols, libdrm, libinput, libxkbcommon,
    pixman, wlroots (>= 0.18), freetype2, openssl, meson, ninja

## Известные ограничения

- glibc: только x86_64
- glibc: только passwd/group/shadow через файлы
- GUI: только Wayland, без XWayland
- VT100: без Sixel, mouse reporting
